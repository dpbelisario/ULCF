91Glossary

This glossary lists the technical terms of all pages in four tables. For each term it gives the Japanese word, a short meaning, the symbol or the name in the code, and the page that explains the term.

1. How to use this page

Keep this page open in a second browser tab, and look up a term when you meet it on another page. The terms are sorted into four tables by subject, and inside a table they are in alphabetical order. The search function of the browser (Ctrl+F) finds a term in any of the tables.

Every row of a table has four cells.

  • English term. The term as the pages write it. A second name that some pages or the code use for the same thing stands in parentheses, for example Symbol rate (baud rate).
  • Japanese term. The Japanese word for the term.
  • Meaning. One or two sentences that agree with the way the pages use the term. The link at the end leads to the section that explains the term in full.
  • Symbol or code name. The symbol in the equations, and the names of the variables and functions of the given code that belong to the term. A dash means that there is none.
Note

Four function names come from the earlier simulation code of the laboratory and do not explain themselves: TL_QAM, amplified_by_EDFA3, adequalizet and DCS_loss. Table 4 explains them under the terms Transmitter function, Amplifier function, Equalizer function and Loss functions. The letter M does not mean what it meant in your practice chapters, the letter N has several meanings in the code, the number of samples per symbol has the name up, and the number of bits per symbol has the name mod_flag: see Oversampling rate and Bits per symbol in Table 3, and the letters M and N in Table 4.

De-interleaverデインタリーバA filter with one input and two outputs: the odd-numbered wavelength channels leave at one output and the even-numbered ones at the other. The JOCN paper has it in front of the pair of ULCF AWGs; this package uses a \(1 \times 2\) splitter in its place (page 17).-
Erbium-doped fiber amplifier (EDFA)エルビウム添加光ファイバ増幅器（EDFA）The optical amplifier of the switch: it amplifies all wavelength channels in its fiber together, without converting the light to an electrical signal. It restores the power, and it adds ASE noise (page 15).amplified_by_EDFA3

Full width at half maximum (FWHM)半値全幅（FWHM）The width of a passband between the two frequencies at which it passes half of the power. It is also called the 3-dB width (page 17).\(W\), FWHM_AWG
Gain利得The ratio of the output power to the input power of an amplifier; in dB it is a loss with a negative sign. Grid (50-GHz grid)グリッド（50 GHz グリッド）The fixed set of optical frequencies on which the wavelength channels lie. On the 50-GHz grid in the C band, the wavelength range that an EDFA amplifies, neighboring channels are 50 GHz apart (page 17).-
Insertion loss挿入損失The loss of an element from an input port to an output port. For an AWG it is the loss at the center of the passband: 6 dB in the three-stage scripts and 9 dB for the ULCF AWG (page 17).AWG_loss

Loss損失The ratio of the input power to the output power of an element, written in dB. Along the path of one signal the losses of the elements add (page 12).-
Multicore fiberマルチコアファイバA fiber with several cores, each of which guides its own light; a fan-in device connects single-core fibers to the cores, and a fan-out device separates them again. The two-stage scripts charge 1.5 dB for each of these devices (page 21).fiber_flag, Fan_in_loss, Fan_out_loss
Noise figure雑音指数The number that tells how much ASE an amplifier produces. The equations use it as a ratio \(F\), and the scripts give it in dB (page 15).\(F\), NF, NF2
Off portオフのポートA port of a selector that is switched off. It still passes a small part of the light, and this light is a leak (page 16).-
Passband通過帯域The range of frequencies that an output port of an AWG passes. This package models it as a Gaussian curve (page 17).gaussfilter
Passband-center deviation通過帯域の中心周波数偏差The difference between the frequency of a wavelength channel and the real center of the passband of the AWG; it is larger when more input ports are used. The scripts simulate the input port with the largest deviation; the values are the specification values of the ULCF AWG device in the laboratory (page 17).ULCF_dev_freq
Pre-amplifier前置増幅器A second EDFA directly in front of the receiver. It carries one wavelength channel, and its noise counts when the power that reaches it is low (page 15).edfa_sat2, NF2
Saturation output power (saturation power)飽和出力The limit of the total output power of an EDFA, all wavelength channels and both polarizations together. The channels that one EDFA carries share it equally, and in the scripts each signal shares its part with the ASE inside one channel spacing (page 15).\(P_{\mathrm{sat}}\), edfa_sat1, edfa_sat2
SelectorセレクタA switch (\(1 \times M\)) that connects its single port to one of \(M\) ports: a tree of \(1 \times 2\) switch elements. Its loss is low, 0.5 dB each time \(M\) doubles, but a port that is switched off still passes a little light (page 12, page 16).selector_loss

Frequency offset周波数オフセットThe distance in Hz by which freqoff moves the spectrum of a signal, for example to another wavelength channel. It must be a multiple of the bin spacing, and the shifted signal must fit into the simulated band (page 14, page 16).\(f_{\mathrm{off}}\), foff
Grid step刻み幅The spacing of the transmitter powers that a search tries: 1 dB in a quick run and 0.5 dB in a full-size run. A required transmitter power is known only to one grid step (page 03, page 21).pin_ary
Hand budget (closed-form budget)手計算のバジェットThe same quantities as the simulation gives, the power after every block and the SNR contributions, but calculated with formulas only, without waveforms and random numbers. HeaderヘッダThe block of comments at the top of a file: what the function or script does, its inputs and outputs with their shapes and units, and notes. The command help, followed by the name of the file, prints it (page 04).-

LibraryライブラリThe folder matlab/lib/: 23 functions, one function per file, that the scripts call. You read the functions and call them, but you do not edit them (page 04, Start here).-
Limit case極限ケースA setting for which you know the answer before you run it, for example \(K = 1\) or a run without noise. Check a limit case before you believe a result that surprises you (page 03, Start here).-

NaNNaN（非数）The MATLAB value for a missing number (not a number). In the tables of the main scripts it marks a switch size that does not reach the FEC limit at any transmitter power that was tried (page 21, page 22).-
Operating point動作点One set of parameter values for one run of the chain: one transmitter power, one size of the space switches, and one \(K\) or one type of the third stage. A step script simulates one operating point (page 21).-
PhaseフェーズA block of work of the project with one goal and one completion condition. The workflow has nine phases, numbered 0 to 8 (page 03).-
Quick run, full-size run短時間の実行、フルサイズの実行The two sizes of a run of a main script. A quick run uses 30000 symbols for each operating point and power steps of 1 dB; a full-size run uses 150000 symbols and steps of 0.5 dB (page 04).quick_flag
Reproducible再現可能A result is reproducible when you, or another person, can produce exactly the same numbers again later. For this, save every result together with its parameters and its seed (page 03).-

Search path検索パスThe list of folders in which MATLAB looks for functions and scripts. The script setup_path puts the folders of the package at its top; run it once in every MATLAB session (page 04).-
SeedシードThe number that starts the random number generator. With the same seed and the same parameters, a run gives the same numbers again (page 03).seed, rng(seed)
Simulated bandシミュレーション帯域The frequency interval that the samples can describe: from \(-F_s/2\) to \(+F_s/2\) around the carrier. Every signal that a script simulates must lie inside it, and a larger oversampling rate makes it wider (page 13).\(F_s\), Fs
Step script, main scriptstep スクリプト、メインスクリプトA step script (step21_..., step22_...) simulates one operating point and prints its power table and its SNR table. Transmission chain伝送系The sequence of elements that the signal passes from the transmitter to the receiver; the step scripts number its ten blocks from [1] to [10]. Transmitter function送信器の関数The library function that makes the waveform of one transmitter: random bits, QAM symbols, pulse shaping and optical power. TL stands for tunable laser (page 13).TL_QAM
Worst case最悪条件The assumption of the given scripts about the leaks: every other input carries a signal of the same power, and every leak has the wavelength of the target signal. In the third stage of the conventional switch this is more than a worst case: all leaks there always have the wavelength of the target signal (page 16, page 21).-
